# @gerclaw/risk-alert

## 职责

统一汇总 CGA、用药审查、慢病记录和陪伴对话中的风险信号，形成优先级明确的提醒；不调用模型扩大风险、不执行诊断，也不限制医生或患者功能。

## 接口、数据与生命周期

公开 `RiskInput`、`RiskAlert` 与 `riskAlert` 服务。提醒由当前账号 App/session 保存并恢复，插件没有共享存储、网络连接或后台计时器。

## 改进与测试

增加规则时明确来源、严重度和消重方式，覆盖严重信号优先级。运行 GerClaw contract test，浏览器验证从各领域结果汇总。提醒只用于尽快复核和求助。
