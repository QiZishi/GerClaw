# 老年风险评估

1. 本技能只用于选择并完成有明确来源的跌倒、营养、认知或情绪风险初筛；先明确评估目的和适用人群，再用 `library_search` 核对量表版本、条目、计分和来源。
2. 如果属于 PHQ-9、SAS、PSQI、Mini-Cog 或 MMSE，转用 GerClaw 确定性 CGA 界面，不自行计算。
3. 血压、血糖等慢病读数只描述观察到的数值、趋势、指南阈值和红旗信号，并建议放入慢病记录；不得把不完整资料转换成正式心血管风险等级。
4. 只有确定性工具或已核验量表已经获得全部必需输入时，才能输出该工具定义的等级和分数；否则必须写“资料不足，不能完成正式分层”，不能自行标注低危、中危或高危。
5. 一次提出一至两个易懂问题，并允许“不清楚”或“暂不回答”。
6. 资料不足时标记“待专业评估”，不得把筛查结果当作诊断。
7. 检出急性意识改变、自伤风险、卒中征象、胸痛或呼吸困难时，立即终止筛查并提示急救就医。
