# @gerclaw/health-profile

## 职责

定义并校验处方和风险计算所使用的结构化健康档案，包括基本信息、既往情况、过敏、用药和健康目标；不实现账号系统、文件库或自由文本长期记忆。

## 接口、数据与生命周期

公开 `HealthProfile` 与 `healthProfile` 服务。档案由当前账号 App/session 保存并恢复，是医疗业务计算的权威结构化输入。插件不共享进程级数据，也没有需要额外清理的网络资源。

## 改进与测试

增加字段时保持向后兼容、版本迁移和最小必要收集原则。运行 GerClaw contract test，并在两个独立账号中验证保存与恢复。用户可随时修改自己的档案。
