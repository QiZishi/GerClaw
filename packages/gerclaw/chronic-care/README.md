# @gerclaw/chronic-care

## 职责

保存慢病项目的测量记录并以确定性算法计算上升、下降或稳定趋势；不推断诊断、不生成处方，也不直接访问其他账号数据。

## 接口、数据与生命周期

公开 `ChronicMeasurement`、`ChronicTrend` 与 `chronicCare` 服务。数据通过当前账号 App/session 持久化并在重启后恢复；插件不持有网络连接、计时器或全局缓存。

## 改进与测试

新增指标时定义单位、时间排序和趋势规则，避免用模型改写数值。运行 GerClaw contract test，并在浏览器验证新增记录、历史顺序和趋势展示。当前仅做趋势描述，不提供医学诊断。
