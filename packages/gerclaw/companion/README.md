# @gerclaw/companion

## 职责

提供支持性陪伴回复和危险信号的确定性识别。为避免敏感资料被不必要扩散，该模式不调用长期记忆、RAG、Web、技能或用户文档；它也不替代专业心理或急救服务。

## 接口、数据与生命周期

公开 `CompanionSignal` 与 `companion` 服务。对话结果只进入当前账号 session，严重信号可交给 `risk-alert` 汇总。插件无后台资源，随 Cordis 上下文直接卸载。

## 改进与测试

扩展信号词时必须覆盖误报和漏报用例，并保持非评判性文案。运行 GerClaw contract test，浏览器验证普通支持与紧急信号。紧急提示会建议联系当地急救或可信赖的人。
