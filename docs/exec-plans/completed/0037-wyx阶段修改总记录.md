## 4. Search 双通道与证据隔离

本阶段仅修改 apps/api/tests/test_search_module.py，新增 AnySearch 首次超时、重试后不可用、Tavily 成功降级的组合用例，验证三次网络尝试各有独立的 egress prepared 和终态记录，并验证三次审计使用同一脱敏查询，不包含姓名或手机号。

- Search API 要求 search:read，外发查询先脱敏并逐 provider 记录审计；
- URL 还受到 HTTPS、DNS、公网地址、重定向和 IP 固定连接校验。

### 7.2 参数与真实验收

当前生产默认参数：

    GERCLAW_RAG_DENSE_RRF_WEIGHT=0.50
    Top-K=5
    GERCLAW_RAG_MIN_RERANK_SCORE=0.05
    chunk min/target/max/overlap=256/384/512/64

使用隔离 collection、完整 436 个 Markdown 文档和真实 Embedding/Reranker 的结果：

| 项目 | 参数 | 结果 | 决策 |
| --- | --- | --- | --- |
| RRF | dense/sparse 0.50/0.50、Top-K 5、阈值 0.05 | 8/8 | 保留 |
| RRF | dense/sparse 0.65/0.35、Top-K 5、阈值 0.05 | 8/8 | 不替换基线 |
| RRF | dense/sparse 0.35/0.65、Top-K 5、阈值 0.05 | 6/8 | 淘汰 |
| 返回数量 | 等权、Top-K 3、阈值 0.05 | 8/8 | 对比通过，不改默认 5 |
| 重排阈值 | 等权、Top-K 3、阈值 0.10 | 8/8 | 与 0.05 无质量差异，不改默认 0.05 |
| 小分块 | 128/256/384/32、等权、Top-K 3、阈值 0.10 | 7/8 | 淘汰 |
| 基线分块 | 256/384/512/64、等权、Top-K 3、阈值 0.10 | 8/8 | 保留 |
| 大分块 | 256/512/768/64、等权、Top-K 3、阈值 0.10 | 7/8 | 淘汰 |

索引结果：

- 小分块：indexed=436、chunks_written=59326、failed=0；
- 大分块：indexed=436、chunks_written=27760、failed=0；
- 基线：indexed=436、chunks_written=39837、failed=0。

两个候选分块均未命中 rag-retrieval.geriatric-anxiety-guideline 的期望文档，因此不替换基线。0.05 和 0.10 均为 8/8，没有足够证据证明 0.10 更好，故保留原默认 0.05。
